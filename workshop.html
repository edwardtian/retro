Workshop

Build your own machines for this mirror: install Windows on a fresh disk, turn it into a reusable Windows image, then install a game on top of it and publish the result to the game list. Everything runs in the browser player - nothing is downloaded from the internet.

New Windows installation

Boots the player from a Windows installation ISO with a freshly created blank hard disk, so the installer can prepare the machine.
How it works
  1. The ISO is uploaded to this server's library and a blank hard disk of the chosen size is created - already partitioned and FAT32-formatted, and mounted as C: with an explicit geometry, so the installer always has a usable system drive.
  2. The player boots a machine with that disk as C: and the ISO as the CD drive.
  3. Boot from the CD and install Windows. If setup stops with "SU0409: Windows 98 Setup was unable to update your system files", install from the hard disk instead of the CD - the classic fix for that error, because the real-mode CD/SMARTDrive path is what fails: 
    md c:\win98
copy d:\win98\*.* c:\win98
c:
cd \win98
setup /is
    (/is skips ScanDisk. Copy whichever folder on the CD holds SETUP.EXE if it is not called WIN98.)
  4. Shut the guest down, then press Download Save File in the player toolbar. That download is your Windows image - bring it back here to Add a Windows VHD.

Add a Windows VHD

Turns an installed Windows disk into a reusable machine image that the other wizards (and games) can boot from.
Where the file comes from
  • The player's Download Save File output can be uploaded here directly: the server pulls the VHD out of the pack (.ddyx or .zip).
  • A plain .vhd / .img disk also works.

New game installation

Boots one of your Windows images and mounts the game's CD, so the game's own installer can run inside the guest.
How it works
  1. The game ISO is uploaded to the library and mounted as the guest's CD drive.
  2. Install the game inside the guest from that CD.
  3. Shut the guest down, then press Download Save File in the player toolbar. That file is the Game DDYX for Add a new game.

Add a new game

Publishes a finished game disk to this mirror's library and game list.
Where the file comes from Upload the Game DDYX the player produced in New game installation (the Download Save File output). A plain .vhd / .img also works. The game is registered against the Windows image it was installed on; it then appears in the game list on the home page.
